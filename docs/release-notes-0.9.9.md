# Egg Launcher 0.9.9

发布日期：2026-10-20

- **扩展 Batch Size、Micro Batch 选项，支持自定义输入**
- **增加五种 n-gram 推测解码策略，支持与 MTP 联合使用**
- **补齐 MTP、MoE、缓存及高级运行参数**
- **增加实验性“自定参数”选项卡，分别支持 llama.cpp 与 Codex 参数**
- **完善参数查重、格式检查及 Codex 配置恢复**
- **增加模板、外置 MTP、视觉模块的重新检测入口**
- **优化能力检测与验证记录复用，减少无关参数造成的验证失效**
- **梳理保存与启动的检查边界，修复不合理拦截**
- **上下文、安全余量、工具结果历史上限统一采用整数 K 输入**
- **仪表盘增加最近一次草稿接受率显示**
- **补齐运行参数的命令名称、简短介绍及中英文悬浮提示**
- **优化模型类型对应的参数显示、按钮布局及界面间距**
- **补齐新增功能的简易与详细诊断日志**

## 审查结果

- 思考开关仍要求开关能力验证通过；档位仍要求真实档位、Responses 和客户端兼容性均确认。支持档位但不支持思考开关的模型仍可开放档位。
- 界面、Catalog 和默认档位选择同时解除关闭思考条件，没有仅放开界面而在配置中丢弃档位。显式关闭思考时原有 false、reasoning off、预算 0 保持，传递的档位不改名、不映射。
- 显示过程仍受有效开启思考约束；默认强度和反转仍受档位开关约束。关闭模块内上方开关仍保留下方偏好，检测异常与失效清理规则保持。
- 在明确关闭思考或已确认模板默认关闭时，开启档位开关、修改默认强度或反转时提示组合可能无效；关闭档位开关不提示，直接关闭。默认选择“不继续”；取消在控件状态变化前拦截该次操作，未确认仍可再次提示。
- 同一参数编辑窗口确认继续后不重复提示，不持久化该确认；重新打开重新判断。初始化、刷新及检测结果填充不会弹出提示。思考开启、状态未知或无思考开关时不误报已关闭。
- 实际配置事务验证关闭思考加 medium 同步成功，Catalog 保留真实档位，显示偏好保留但实际显示关闭，在线原配置恢复。没有绕过验证与事务。

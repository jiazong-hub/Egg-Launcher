# 0.9.9 接受率、整数 K 与参数提示审查

日期：2026-10-20。依据当前源码，不将界面显示视为模型性能或兼容性证明。

## 接受率来源与状态

- `DraftAcceptanceParser` 只接收 `slot print_timing` / `print_timings` 单请求 `draft acceptance` summary，保留原生比率和 accepted/generated；校验范围与计数一致性，不读取全局累计统计、不合并请求、不推算缺失值。
- 进程管理器在简易日志过滤前提取；详细模式关闭或日志文件写入失败后继续排空时，仍可收集有效统计。新增显示不要求开启详细日志。
- Agent 仅对启用 MTP 的实际运行模型发布可选 RuntimeState 快照。没有新数据时保持最后值，不新增高频轮询；MTP+n-gram 显示为整体草稿统计。
- UI 核对 Router 进程及启动时间、模型、阶段和状态新鲜度。无结果显示短横线 `–`，有效零值显示 0.0%；换模型、服务重启/停止、在线模式不能继承上一运行的值。
- 速度、接受率、上下文同排；速度使用等价缩写 t/s。浅/深色、中/英文及窄侧栏保持对齐。

## 输入与说明

- 新输入使用整数 K，不需要 K 后缀；保存及实际传递仍用 tokens。旧非整 K 值显示并保留原数值，不静默舍入；原 `LongConversationLimits` 关系不变。
- 参数悬浮说明补齐接收者、命令/配置键、用途，保留原路径与动态范围。模型列表按钮顺序与资源移除图标仅调整 UI。

# 0.9.8 发布检查记录

发布日期：2026-10-18。源码版本为 0.9.8 / 0.9.8.0，本版基于既有 llama.cpp、Codex 集成方式完善配置与管理体系，没有增加新的视觉原生验证流程。

## 用户确认与范围

- 用户确认最新视觉页界面修正测试包运行稳定，并于 2026-10-18 授权发布、同步文档、源码及安装包。
- 用户反馈关闭 OpenAI 认证后本地模式不显示额度与账户信息，仍可阅读在线项目；不推导跨 Provider 原任务可以继续发送。
- 0.9.7 的安装、升级、卸载恢复与 Windows 10 CUDA/Vulkan/CPU 稳定性实测保留为历史依据。0.9.8 的整体稳定反馈不代替全部安装、异常注入或硬件矩阵逐项验收。Windows 11、ROCm 尚未测试。

## 源码与检查依据

- 最新测试构建通过 654 项全量自动化测试；505 项隔离 WPF 回归和 17 项视觉界面检查通过。
- 最新视觉页调整仅删除重复标题；下拉框到下方参数保持 12 DIP 间距，无残留占位，内部资源路径及事件处理保留。
- 配置与模型绑定、路径限制、类型不符拒绝、预选同步、失效资源拦截、已应用快照及独立 OpenAI 恢复由现有测试覆盖。
- 诊断沿用简易/详细 JSONL，不逐次记录界面输入。版本查询失败不阻止启动，视觉识别不扩大为图片推理验证。
- 历史分阶段测试数见各日期审查文档；它们不是最终构建总数。早期暂缓的 A09（预选文件恢复后的旧错误状态）随后已在卡片配置预选的统一状态解析中解决，见[卡片配置预选审查](mode-card-configurations-review-20261017.md)。

## 正式发布流程

正式包从提交后的源码重新构建，不直接将未签名测试包改名。发布脚本依次执行锁定依赖恢复、Release 零警告构建、格式检查、全量测试、在线依赖漏洞审计、发布后 Agent 自检、Runtime 许可复制、作者证书签名与逐文件校验。任何门禁失败均不能将其记为通过或公开对应安装包。

沿用项目作者证书签署 Launcher 自有 EXE/DLL、安装器和卸载器；证书指纹及自签名边界见[签名策略](signing-policy.md)。不导出私钥，不安装系统信任根。

发布资产包含 Windows x64 安装包、便携 ZIP、源码 ZIP 及 SHA-256 校验文件；大型二进制作为 GitHub Release 附件，不放入源码 Git 历史。源码提交与 v0.9.8 标签必须一致，推送不覆盖其他提交或既有版本资产。附件大小和 SHA-256 应与本地一致，公开后再次核对最新 Release、标签和文件清单。

最终执行结果以发布包 `BUILD-INFO.txt`、`SHA256SUMS.txt`、GitHub Release 附件及本地 `artifacts/release-0.9.8` 校验记录为准。安装或模型真机验收不在当前开发客户端运行期间执行。

# Egg Launcher 0.9.3（公开测试版）

0.9.3 将 Windows x64 交付方式从 ZIP 改为当前用户的单文件 EXE 安装包。

## 变化

- “关于”页面新增“更新日志”选项卡，简要记录 0.9.0-beta、0.9.1、0.9.2 和 0.9.3。
- 复用原有发布门禁，将自包含 App 和 Agent 目录编译为 Inno Setup 安装程序。安装程序提供开始菜单快捷方式，可选桌面快捷方式，不默认开启登录启动。
- 卸载确认后，先要求 ChatGPT Desktop、启动器和 Agent 完全退出；如果当前为 Local 模式，复用恢复事务切回 OpenAI。恢复失败时不删除程序文件。
- 卸载保留离线 Local 历史 Provider、设置、备份、模型和 Runtime；仅移除本次安装文件、快捷方式，以及确实指向本次安装路径的登录启动项。

## 实测结果与已知限制

- 测试环境：Windows 10 企业版 22H2，操作系统内部版本 19045.5371。
- 启动、基本使用、界面动画、模式切换与启动运行稳定；全新安装和旧版升级顺利完成。
- NVIDIA CUDA 后端当前状态稳定。AMD Vulkan 后端可能偶发重连报错；尚未使用 ROCm 后端测试。
- 不建议绕过 Egg Launcher 直接启动 ChatGPT Desktop，以免客户端使用的接口与启动器当前配置状态不一致。
- 卸载流程及卸载时恢复 OpenAI 配置尚未测试；Windows 11、ROCm 和其他硬件组合也未覆盖。
- 安装包与卸载程序签名、SHA-256 清单由发布脚本检查；实际卸载和完整安装目录一致性仍待进一步验收。
- 安装包由项目自签名证书签署。它用于校验签名和作者连续性，不构成 Windows 公共信任；用户首次下载运行时可能看到安全提示。证书指纹见[签名策略](signing-policy.md)。

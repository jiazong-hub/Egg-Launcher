# Egg Launcher 0.9.3（发布候选）

0.9.3 将 Windows x64 交付方式从 ZIP 改为当前用户的单文件 EXE 安装包。版本尚未完成安装、升级和卸载真机验收，因此本文件暂为发布候选说明。

## 变化

- “关于”页面新增“更新日志”选项卡，简要记录 0.9.0-beta、0.9.1、0.9.2 和 0.9.3。
- 复用原有发布门禁，将自包含 App 和 Agent 目录编译为 Inno Setup 安装程序。安装程序提供开始菜单快捷方式，可选桌面快捷方式，不默认开启登录启动。
- 卸载确认后，先要求 ChatGPT Desktop、启动器和 Agent 完全退出；如果当前为 Local 模式，复用恢复事务切回 OpenAI。恢复失败时不删除程序文件。
- 卸载保留离线 Local 历史 Provider、设置、备份、模型和 Runtime；仅移除本次安装文件、快捷方式，以及确实指向本次安装路径的登录启动项。

## 待验收

- 干净 Windows 10 22H2 / Windows 11 x64 标准用户安装、启动、升级和卸载。
- 0.9.2 便携版数据迁移、登录启动路径修复、运行中安装或卸载阻断、Local 模式卸载后官方模式与旧历史查阅。
- 安装器和卸载程序签名、哈希与已安装文件一致性，以及所选安装位置的登录启动安全校验。

# 思考过程显示测试版：实现与小规模审查（2026-10-07）

基于 v0.9.7，新增每个模型独立保存的“显示思考过程”，默认关闭，位于“启用思考”下方。启用思考关闭、开关能力未确认或检测中时置灰，保留显示偏好；沿用模板默认且默认开启时可操作。支持保存为模型默认及恢复默认。

## 显示链路

只读检查当前 Desktop 安装资源后，确认聊天区的思考渲染读取 reasoning.summary，原始 reasoning.content 会被接收但不在此处展示。因此不能只写 show_raw_agent_reasoning。

本地代理开启显示时保留原始 reasoning_text 事件，并增加 Desktop 使用的 summary 流事件；完成条目保留原始 content 并填充空 summary。原生已有的摘要不覆盖。关闭时沿用原始响应流。此处 summary 通道承载的是原始思考全文，不是另一个模型生成的摘要。

再次提交历史时，只清除与原始 reasoning_text 完全相同的展示副本；保留原始 content、真实摘要、思考开关及档位。清理覆盖普通 Responses 及专用 compact 路径，避免重复的展示文本进入模型输入。没有修改模板生成或档位验证指纹。

show_raw_agent_reasoning 同步到本地配置事务；切回在线模式恢复原值（含原本不存在的情况）。新增参数的原始状态从经过哈希校验的历史配置备份补齐，兼容旧恢复记录。运行中的代理通过 Profile 文件变化更新显示偏好，每次响应固定自己的显示处理状态。

## 审查结果

已处理的问题：

- 单独配置 raw 显示参数不满足当前 Desktop 的渲染链路，增加响应显示兼容处理。
- 重复展示文本可能进入后续模型输入，增加精确的副本清理。
- 改写 SSE 后原 Content-Length 不再有效，开启兼容处理时移除该长度。
- 旧恢复记录缺少新参数，使用已验证的原始备份补齐恢复基线。
- 新默认字段可能影响既有上下文能力指纹：默认 false 不序列化进参数快照，计算上下文能力指纹时排除显示偏好。

验证：

- 384/384 自动测试通过，包括实际回环代理、逐字节 UTF-8 分块、原始内容保留、摘要同步、既有摘要保留、异常帧、4 MiB 以上帧透传、后续输入清理、模型默认恢复、旧配置恢复记录的原值 true/false/缺省。
- Release 解决方案构建：0 警告、0 错误。
- WPF 界面在 820/640 宽度渲染检查；开关默认关闭、联动置灰、检测中置灰、保存捕获、取消隔离及缺失模板恢复状态检查通过。
- 使用当前 Desktop 配套 CLI 及独立临时 CODEX_HOME，连接本地模拟 SSE：关闭时原始内容存在且 summary 为空；开启后收到 summaryTextDelta，完成条目的 summary 与原始 content 相同。两种情况下均正常完成。
- Desktop 安装资源中的聊天渲染分支读取完成条目的 summary，和上述协议验证结果相符。

范围限制：未在用户的 7900XT/27B 上执行真实生成，也未操作现有 Desktop 会话。测试包需现场验证开启后流式显示与关闭后隐藏；历史会话不会自动补显示。这是测试版，不发布 GitHub Release。

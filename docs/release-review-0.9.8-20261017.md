## 本次修正

参数页启动上下文滚动或思考检测后，旧保存按钮会禁用，但新增加的载入按钮仍能打开另一份配置。旧检测随后完成时，结果可能回填到已经切换的编辑页面。保存和启动的证明检查会继续生效，但界面可能混入非用户预期的检测状态。

修正为检测期间同时禁用“应用”和“载入配置”，载入与保存方法再次检查检测状态。检测结果完成、失败或取消清理后恢复按钮。保留取消关闭行为和现有验证方法，不增加新的检测流程。

隔离复现检查使用可控的异步检测替身：A 检测未结束时尝试载入 B，确认拒绝载入、编辑对象和 JSON 不变、应用不落盘；完成 A 检测后确认按钮恢复、B 能正常载入；思考检测同样阻止配置替换。思考检测中指向基础参数的两条旧提示改为当前模板设置与模型管理入口。

# Egg Launcher 0.9.2 用户功能说明

本文说明本地标签 v0.9.2 的功能。启动器是 llama.cpp 与 ChatGPT Desktop 之间的管理外壳，不重复实现推理、KV Cache、模型调度或语义摘要。沙箱设置仍为 beta，完整验收状态见[版本说明](release-notes-0.9.2.md)。

## 1. 模式与数据边界

- `OpenAI` 与 `Local LLM` 互斥；切换前必须完全关闭 ChatGPT Desktop。
- 关闭启动器或客户端不会自动切回 OpenAI；当前模式和所选本地模型会保留。
- 用户可在 ChatGPT 关闭后直接执行 Local 模型 A → B，不必先回到 OpenAI。
- 项目、任务历史和开发上下文共用；Provider、可见模型列表和请求目标隔离。
- Local 复用 ChatGPT Desktop 的账户外壳以显示原生项目与历史，因此仍可能看到官方账户名称或额度提示。这不代表请求发送到 OpenAI。
- 本地代理会在请求进入 llama.cpp 前移除 Authorization、Cookie 和账户相关 Header。
- 切回 OpenAI 时恢复进入 Local 前的官方模型、思考强度、详细程度、服务层级、上下文和权限字段。
- 切回 OpenAI 后，启动器保留一个未激活的本地历史 Provider 定义，供客户端识别和查阅旧 Local 对话；当前官方模型仍按官方路由运行。跨模式支持查阅历史；原任务跨 Provider 续聊方案已放弃，请在目标模式新建任务继续开发。

## 2. 首页

### 界面语言

- 默认跟随 Windows 显示语言：中文系统使用中文，其他系统语言使用英文；只在启动时读取，不进行后台轮询。
- 语言按钮仍显示当前实际语言 `ZH` 或 `EN`。单击会切换并固定为中文或英文；右键选择“跟随 Windows 显示语言”可恢复自动模式。
- 从旧版本升级时，原有中文/英文设置会迁移为“跟随系统”。Windows 显示语言改变后，重启 Egg Launcher 即可应用。

### 外观与提示

- 首页设置卡片右上角提供语言和深色/浅色切换；主题、语言与主窗口状态持久化保存。
- 浅色与深色模式使用同一布局和功能层级，只调整背景、卡片、边框、文字和强调色。
- 底部提示条可手动关闭，并在显示约 10 秒后自动消失；新的提示会替换旧提示并重新计时。
- 页面切换、选项卡和弹窗使用短时轻量动画；功能卡片不使用持续悬停位移，避免布局抖动和复选框闪烁。

### 当前持久化模式

- `OpenAI`：确认后恢复官方 Provider 配置并启动 ChatGPT Desktop。
- `Local LLM`：进入本地模型选择，不会仅因点选标签而立刻改写配置。
- 当前模式显示来自持久化配置，不等同于某个进程此刻是否运行。

### 环境状态

- ChatGPT Desktop：运行中或已关闭。主窗口位于前台时低频刷新，最小化或隐藏后暂停；模型管理和托盘交互会按需读取一次最新状态。
- Launcher Agent：停止、运行、身份不匹配或异常。
- llama.cpp：停止、Router 就绪、模型已加载、模型已休眠或异常。
- llama 后端：显示 llama 当前报告的 CPU、CUDA、Vulkan、ROCm 等后端信息；无法证明时显示不可用，不根据显卡名称猜测。
- 运行模型：放在状态卡片最下方，显示当前实际配置的本地模型。
- 切换、保存和恢复期间显示忙碌状态并禁止重复操作。

### 后台启动与诊断

- `登录 Windows 时启动后台 Agent`：写入或移除当前用户 Run 项；不使用管理员服务。
- 启动项只允许指向可信固定目录中的同包 Agent；可被普通用户组或沙箱修改的路径会被拒绝。
- `打开诊断日志文件夹`：打开 `%LOCALAPPDATA%\ChatGPTLocalLauncher\logs`。

### 托盘

- 单击托盘图标打开或恢复主窗口；右键菜单依次提供打开 Egg Launcher、启动 ChatGPT、当前模式、切换模式和退出。
- “切换模式”子菜单与模式页面状态一致；不可用的模式或操作在托盘中同样禁用。
- 托盘状态提示按多行显示当前模式、ChatGPT、配置状态、llama 服务、llama 后端和运行模型。
- 菜单打开或请求状态提示时只刷新一次，不进行常驻后台轮询；语言切换后直接使用同一状态快照重新格式化。

## 3. 本地模型页

### llama.cpp Runtime

- `选择文件夹`：选择包含 llama.cpp 可执行文件的 Runtime 根目录。
- 探测内容：版本、Router、空闲休眠、Chat Template、metrics 和设备列表等能力。
- Local 模式或当前 Runtime 的服务运行时禁止更换 Runtime。
- 缺少必要目录时会询问是否创建；能力不足时显示具体诊断。
- `搜索并下载 GGUF（实验性）`：打开模型搜索与下载窗口。

### 扫描结果

- `扫描模型`：扫描 Runtime 的 `models` 目录。
- 支持单文件 GGUF 和完整多分片 GGUF；缺失分片会报告异常。
- `mmproj` 不作为独立主模型加入。
- `添加选中模型`：建立 Profile、BAT、Catalog 和 preset；不会加载模型或启动 ChatGPT。
- 首次添加后可选择调用 Runtime 的 `llama-fit-params`，应用前必须由用户确认。

### 已管理模型

- 模型列表显示所有已管理 Profile，并保留当前选中项。
- 名称前显示 `【Dense】`、`【MoE】` 或类型未指定；具备已确认能力时继续显示 `【Vision】`、`【MTP】`。能力标识表示可用，不表示已经开启。
- 新模型只在首次添加时读取元数据识别 Dense/MoE；旧 Profile 或无法识别的模型由用户手动指定，不在每次打开页面时重复扫描。
- 更改已确定的模型类型会重建该模型参数配置，避免 Dense/MoE 参数混用；模型文件保持不变。
- 摘要显示名称、别名、来源、路径、总大小、分片、当前参数和专用默认值。模型文件被外部删除后条目变灰并提示不可用。
- `编辑运行参数`：模型类型明确且文件存在时打开参数窗口。
- `模型类型`：指定或更改 Dense/MoE；更改既有类型前会说明配置重建影响。
- `由 llama 自动适配`：展示原生建议；可选择应用并保存为当前模型默认。
- `模型详情`：显示文件、来源、大小、分片、架构、参数量、训练上下文、模态与运行参数；部分信息仅在 llama 已运行且返回时可用。
- `检测思考档位`：使用隔离验证确认模型是否支持可枚举档位；不支持与档位未知分别客观提示。
- `加载/移除外置 MTP`、`加载/取消视觉关联`：只改变当前模型的辅助能力关联，不删除辅助文件。
- `在模式卡片中显示/隐藏`：控制该模型是否出现在模式页面，不影响 Profile 和磁盘文件。
- `从列表中移除`：删除 Launcher Profile 和受管生成物，不删除主模型、MTP、mmproj 或 llama 缓存数据。当前正在运行的模型不能移除；若只是当前配置模型，会先给出切回 OpenAI 的建议与确认。
- 同一路径模型再次添加时会重建 Profile；扫描和下载自动登记均排除已经管理的模型，避免二次添加。
- `切换并启动`：确认模型和上下文后写入 Local 配置，启动 Agent/Router，验证 Responses 路径，再启动 ChatGPT Desktop。
- 扫描结果和已管理模型列表可各自滚动；列表到达边界后，继续滚轮会滚动外层页面。

## 4. 模型参数窗口

窗口按顺序使用六个选项卡：`基础参数`、`视觉模块`、`MTP 推测解码`、`高级参数`、`沙箱设置`、`模型信息`。各页内容背景使用统一宽度，每个选项卡独立滚动；底部恢复、取消、保存与保存为默认按钮保持固定，并与内容背景左侧对齐。

### 基础参数

- 显示名称：可编辑。
- 别名与模型文件：只读。
- Context：4K、8K、16K、32K、64K、80K、128K，对应 llama.cpp `-c`。
- 压缩安全余量：1K、2K、4K、8K、12K、16K、24K、32K。
- Codex 压缩线：`Context - 压缩安全余量`；安全余量不是输出 token 上限。
- Context 低于 16K 时仅提示风险，不自动修改或阻止保存。
- GPU Offload：Auto、All、0（仅 CPU）。
- Flash Attention：Auto、On、Off。
- K/V Cache：F16、BF16、Q8_0、Q4_0、Q4_1、IQ4_NL、Q5_0、Q5_1、F32。
- Batch：Default、128、256、512、1024、2048。
- Micro Batch：Default、64、128、256、512。
- 并发 Slot：1、2、4。
- 空闲释放：30 秒、1 分钟、5 分钟、15 分钟、禁用。
- Jinja Chat Template：开关及可选模型专用模板文件。
- 思考强度：位于基础参数末尾。只有模型管理已经确认支持并获得明确档位时开关可用；关闭时不会在启动阶段重新检测。具体档位由 ChatGPT 客户端依据 llama 暴露的能力显示。

### MTP 推测解码与视觉模块

- MTP 推测解码：默认关闭。主 GGUF 带有可识别的 NextN/MTP 层时会显示为内置来源；外置文件必须先在“本地模型管理”中选择，并通过 llama.cpp 的联合加载与极短推理验证。验证成功只建立关联，不会自动打开 MTP。
- MTP 常用参数：N Max、N Min、P Min、P Split 与后端采样；留空时不写入 Profile，继续使用 llama.cpp 默认值。
- 外部 MTP 可单独设置 GPU Offload、设备、K/V Cache 与线程数。外部文件不会作为独立聊天模型加入模型列表；移除关联也不会删除磁盘文件。
- “本地模型管理”会在模型类型后显示 `【MTP】`：内置 MTP 候选或已通过联合加载验证的外置 MTP 才会显示。取消外置关联，或外置文件被删除、替换后再次进入管理页，标识会自动撤销且 MTP 开关会关闭；此检查只在相关操作时执行，不进行后台轮询。
- Hugging Face 仓库中的 MTP 候选文件按单文件任务下载。下载成功后只保存到 Runtime `models` 的启动器受管理目录，不自动关联任何模型；用户需在“本地模型管理”中自行加载和验证。主模型下载成功后仍会自动添加到模型管理。
- 内置 MTP 在启用后的首次正式启动中由 llama.cpp 原生验证；外置 MTP 在建立关联前即完成隔离验证。主模型、辅助文件或 Runtime 变化后验证失效，普通 MTP 参数调整不会抹掉文件兼容性结果。
- 视觉模块位于“基础参数”和“MTP”之间。只有通过 llama.cpp `/models` 图片能力检查及真实 `input_image` 请求的配置才可开启，并在模型名前显示 `【Vision】`。
- 外置视觉模块使用与主模型匹配的 `mmproj` GGUF。“加载视觉模块”只建立当前模型的关联，不会把 mmproj 注册为聊天模型；取消关联不会删除文件。主模型、mmproj、Runtime/MTMD 库或 Chat Template 发生变化时，验证自动失效且开关关闭。
- Hugging Face 中识别出的 mmproj 以单文件任务下载到 `models\egg-launcher-vision`，不会自动关联模型。视觉参数留空时保持 llama.cpp 默认值，可选项包括投影器 GPU Offload、设备、图片 Min/Max Tokens 和 MTMD Batch Max Tokens。
- ChatGPT 仅在视觉功能已经验证并开启时看到 `text + image` 输入能力。本地代理只转发 `data:image/...` 图片，不代替客户端下载远程图片，也不接受 `file:`/HTTP(S) 图片引用。

### 高级参数与模型信息

- 高级参数包含 llama.cpp 支持但不属于常用基础项的运行参数；Dense 与 MoE 根据模型类型显示适用内容。
- `Context Checkpoints` 对应 llama.cpp `--ctx-checkpoints`：留空使用 Runtime 默认值，0 关闭检查点；关闭可能增加长前缀恢复时的预填充耗时，不改变 Codex 自动压缩阈值。
- MoE 可设置专家相关的 CPU/GPU 放置等参数；实际支持仍由当前 llama.cpp 构建和模型架构决定。
- 所有可选参数在用户没有调整时保持未设置，不会为了填满配置而覆盖 llama.cpp 默认值。
- 模型信息包含显示名称、Alias、模型文件和模型类型；Alias、文件与类型不在此页直接改写。
- `恢复此模型默认`：仅当当前模型已保存专用默认快照时可用。
- `保存`：保存当前 Profile。
- `保存并设为此模型默认`：保存并更新当前模型自己的默认快照，不影响其他模型。
- `取消`：放弃本次编辑。
- Local 客户端、Agent 或当前 Runtime 的 llama 服务运行时，所有模型参数编辑与自动适配均禁用。

### 沙箱设置

- 此页为当前模型保存 Codex 命令沙箱权限，与 llama.cpp 参数和审批方式分开管理。
- 联网选项为“沿用 Codex 默认联网设置”“禁止命令联网”或“完整联网”。联网设置只针对受沙箱控制的命令；网页、浏览器和连接器仍由各自功能与策略控制。
- 额外路径必须是绝对目录。未勾选“允许写入”时授予只读访问；勾选后授予读写访问。不能直接授权整个磁盘或共享根目录。
- 模型配置结构版本为 7。旧 Profile 的沙箱字段为空时，启动器不自动写入沙箱配置，继续使用原有 Codex 设置。只有用户修改沙箱选项后才保存该模型的个性化权限。
- 模型切换并启动 ChatGPT 时应用该模型的沙箱设置；切回 OpenAI 时恢复原始沙箱字段。审批策略 `approval_policy` 和 reviewer 设置不由此页修改。
- Codex 命名权限配置目前为 beta 能力。若原配置使用 `:danger-full-access` 或命名配置无法保留的临时目录排除规则，切换会安全中止并提示冲突。

## 5. 运行与缓存页

### 设备与运行监控

- CPU：型号、逻辑处理器、实时占用率。
- 内存：模块厂商、容量、类型、频率、已用/总量；系统未公开的字段显示不可用。
- GPU：适配器名称、总占用、Compute/CUDA、总显存和 llama 显存。
- llama 进程：进程数、CPU 和 RAM。
- `/models`：当前模型加载状态。
- `/metrics`：请求、Prompt/输出 token 与 token/s；不支持 metrics 的 Runtime 不阻断核心运行。
- `/slots`：Slot、KV Cache 和实际已用 token。该数值包含系统提示、项目上下文和工具 schema，通常高于窗口可见文字。
- `立即刷新`：主动更新一次所有可用指标。

### 模型驻留控制

- `立即加载当前模型`：调用 llama 原生 `/models/load`。
- `立即释放当前模型`：调用 llama 原生 `/models/unload`；下次请求可重新加载。
- 有活跃请求、状态未知、目标不匹配或服务不可用时禁止操作。

### 缓存管理

- `刷新缓存`：读取 llama 返回的可删除缓存及其来源。
- `删除选中缓存`：仅处理 llama `can_remove=true` 且 Profile 记录为 Launcher 下载的模型。
- 删除前必须确认；Local 运行中、手工 GGUF 和来源不明 Profile 禁止删除。
- 删除模型缓存不会删除官方账户、项目或历史。

## 6. 模型搜索与下载（实验性）

- 搜索框支持按钮或 Enter 搜索公开 Hugging Face GGUF 仓库。
- 页面三个区域依次为输入框、搜索结果、可下载的 GGUF 量化版本，使用统一边界和对齐。
- 鼠标位于结果框内时可滚动结果；到达结果框边界后，滚轮继续滚动外层页面。底部“关闭”按钮右边缘与结果框右端对齐。
- 仓库信息包括作者、用途、许可证、下载量、更新时间和 gated 状态。
- 变体信息包括量化、大小和分片数量。
- `当前模型仓库`：选择搜索结果后用默认浏览器打开对应 Hugging Face 仓库。
- `当前模型版本`：选择量化文件后打开该文件/版本页面；点击空白取消选择时两个跳转按钮同步禁用。
- `下载选中变体`：检查磁盘空间后，通过临时 llama Router 原生下载到 Runtime 的 `models` 目录。
- 下载状态显示阶段、已下载/总字节、百分比和滚动速度。
- `取消下载`：请求 llama 取消；下载进行中必须先取消才能关闭窗口。
- gated/私有模型暂不支持；Launcher 不自行实现断点续传、文件传输或格式转换。
- 下载失败不会影响已经稳定的模型扫描、模式切换和本地推理。

## 7. 上下文压缩

- llama.cpp 按 Context 管理硬容量、KV Cache 和推理。
- Launcher 把每模型 `Context - 安全余量` 写成 Codex 可见的自动压缩线。
- Codex 监控真实 token，并在安全节点通过当前本地模型生成摘要，再用“摘要 + 最近原文”重建历史。
- Launcher 不猜测下一次回答长度，不生成摘要，不限制单次输出，也不保存第二套对话。
- 压缩摘要质量取决于模型能力、量化、KV Cache 精度和 Context；参数修改后会在允许保存时同步到 Profile、BAT、Catalog 和 preset。

## 8. 关闭行为

Local 服务运行时关闭启动器会显示：

- `取消`：返回启动器。
- `仅关闭窗口`：保留 Agent、代理和 llama Router，ChatGPT Local 继续可用。
- `停止服务并退出`：停止启动器拥有的后台服务，但保留 Local 模式与 Profile；已打开的 Local 客户端不能继续请求。

OpenAI 模式关闭启动器时会结束不再需要的 Agent。若正常停止失败，只有在路径、PID、启动时间、协议和心跳全部匹配时才允许询问强制终止；所有权不明的同名进程不会被结束。

## 9. 重要提示与对话框

- `保护旧版配置备份`：建议选择“是”；程序先 DPAPI 加密并回读验证，再删除对应明文备份。选择“否”不会影响当前配置，但以后仍会提示。
- Local 启动确认：显示模型、Context、账户外壳、凭据剥离、权限归属和官方配置恢复说明。
- OpenAI 恢复确认：只恢复受管 Provider 字段，不清空账户、项目或历史。
- Context 低于 16K：风险提醒，不阻止用户决定。
- 参数无效：列出全部错误并阻止保存。
- 缓存删除：提示不可逆并要求确认。

## 功能与边界

- 每次展开下拉菜单，读取最新模型登记，扫描 `scripts/profiles/configurations/<model-id>` 直属的 JSON。复用现有路径约束，忽略子目录、备份及非 JSON 文件，不允许链接绕过目录范围。
- 菜单名称隐藏后缀，长名称省略，悬停显示完整路径；当前文件右侧显示 `√`，长列表滚动。没有文件时只有不可点击且无勾选的“暂无配置文件”，不提供固定“无”选项。
- 扫描和记录选择不解析 JSON 参数、不检查能力、不验证模型类型或附件。存在但损坏、属于其他模型或类型不适用的文件仍可被预选；既有载入/启动校验负责拒绝，不把“文件可选”当作“可以运行”。
- 选择只原子更新模型登记的 PreferredConfigurationPath 与必要的初始化标记；保留最新名称、类型及未知元数据，不写所选 JSON、其他配置、模板、外挂、生成物或全局 settings.json。只读刷新参数预览不作为预选准入条件。
- 点击相同选择不重写登记。写入前重新检查路径、文件存在性和模型占用，并检查登记是否已被其他操作改动；失败不提交新的选择。没有新增文件监听、配置历史或能力验证机制。
- 预选文件不存在时，卡片与参数页显示“无”，菜单无勾选，新启动资格失效。不清理或重建源文件，不改选其他 JSON，不必清空保留的登记路径。原路径恢复后可重新识别，但不会推断改名或替用户选择其他文件。
- 文件存在但内容有误时继续显示文件名。权限、路径等读取错误保留错误提示，不一律解释成删除，也不因此修改登记。
- 卡片轻量状态刷新只检查预选文件存在性，完整目录列表在展开菜单时重建；打开参数页也扫描目录并重新读取登记和选定配置。没有递归搜索或实时文件系统监控。
- 参数页“应用”先保存当前载入 JSON，再更新同一配置预选；“保存”“另存”不改变预选。返回卡片后显示最新预选。卡片选择后再次打开参数页读取同一记录。
- 参数页刷新启动名称不依赖旧 ConfigurationError，因此恢复文件后不会继续显示旧“无”；只更新名称及路径信息，不覆盖编辑控件、修改 JSON 或自动应用。
- 按实际占用而非模式卡片勾选判断运行模型。运行模型的三个按钮全部禁用，其他未运行模型仍按原有条件允许操作；启动、停止、文件预选提交和窗口打开期间防止重复或冲突操作。模型管理和参数页继续使用原模态窗口及原权限检查。
- 按钮子元素的鼠标事件不会触发卡片预选或长按排序；配置菜单项也不改变全局模式/模型预选。OpenAI 卡片不显示这三个模型操作。
- 真正启动时继续重新读取预选文件，缺失或不可用就拒绝，不回退到旧 BAT / Catalog / Router preset。运行会话和已有快照恢复保持原规则。

## 复审中的修正

1. 配置提交后原先准备复用通用导航刷新，该方法可能顺带迁移其他模型或补写全局预选元数据。改为仅更新本模型预览与列表，并核验全局 settings.json 的字节完全不变。
2. 新增按钮的鼠标按下及释放均识别交互子元素，防止事件冒泡误选卡片和长按拖动。
3. 英文操作名称按现有文本换行，调整前两项宽度避免 management 被裁切；中英文、明暗主题均检查。
4. 开始打开模态窗口时就设置入口保护，避免异步读取期间重复打开窗口或启动；模态退出后恢复状态。

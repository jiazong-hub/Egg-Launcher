# Egg Launcher 0.9.4（公开测试版发布候选）

本版本完善长对话上下文设置、沙箱联网与目录兼容，增加详细诊断日志，并优化参数和卡片界面。目前尚未公开发布，实际发布日期以 GitHub Release 为准。

## 主要变化

### 长对话与上下文

- Context、压缩安全余量、工具结果历史上限、上下文滚动集中设置，支持整数 tokens/K 输入及范围联动。
- 余量满足 `Context < 11 × 余量`，自动压缩线 `Context − 余量` 至少 1,024 tokens；显式工具结果上限至少 1,024 tokens 且严格小于余量。10% 摘要空间是经验预留，不能保证所有压缩请求成功。
- 滚动开关显式输出 `--context-shift` 或 `--no-context-shift`；开启前验证能力，不支持时提示原因。高级参数提供可选 `--keep`，不自动指定保留量。
- 滚动会丢弃较早的 KV 上下文；它不修改 Codex 历史，也不替代 Codex 原生压缩。工具结果上限管理保留到历史的工具输出，不限制命令的原始输出或整轮命令数量。

### 沙箱与联网

- 按模型保存命令联网和额外目录权限；命令审批策略仍由 Codex 控制。
- 提供可选联网兼容环境及 Python/OpenSSL HTTPS 工具，保留证书校验；不透明替换 git、pip、npm、Gradle 等工具。
- 联网检查运行于独立 Codex 沙箱，不需要模型启动，检测结果不代表已有聊天权限。客户端重启并新建聊天后验证新设置。
- 常用目录快捷菜单与自定义路径并存；检测不创建或迁移目录，支持重试和关闭窗口取消。
- Gradle 目录可显式用于 GRADLE_USER_HOME，默认关闭；已有变量冲突需要用户明确选择。只应用于本地配置，关闭、切模型或返回 OpenAI 时恢复基线，不修改系统变量或 Java user.home。
- HTTPS 工具默认请求建立预算 30 秒、连续无数据等待 30 秒；支持分别设置，持续下载无总时长限制，不提供断点续传。

### 界面与诊断

- 参数控件统一高度、字号、圆角和列间距，改善卡片文字/按钮对齐、模式卡片与侧栏自适应。
- 主窗口设定最小尺寸，工作区过小时允许滚动；移除 Logo 下方副标题。
- 首页增加详细日志开关；日常使用精简记录，复现问题时启用详细记录。文件名包含 concise/full。
- 结构化诊断避免对话正文和认证数据；详细原生服务输出可能含本机路径、模型名或第三方文本，分享前需检查并脱敏。

## 升级与使用

1. 升级前关闭客户端、启动器和 Agent，并备份启动器用户数据。
2. 运行正式签名安装程序，保留原模型和 Runtime；新版 Profile 按迁移逻辑读取旧配置，参数不满足新关系时按界面提示修正。
3. 根据模型设置上下文和余量；滚动有遗忘风险，按需求选择。
4. 命令联网出现兼容问题时再启用兼容选项；目录权限只添加任务需要的路径。
5. 权限或环境配置改变后重启客户端、新建聊天验证；故障时开启详细日志。

新版 Profile 不保证被旧程序读取；退回旧版应使用相应数据备份，不能只重装旧 EXE。

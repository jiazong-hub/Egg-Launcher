## 范围

- 原 MTP 推测解码选项卡改为推测解码，保留现有 MTP 来源、验证与参数。
- 新增 n-gram 总开关（默认关闭）及五种类型多选：simple、map-k、map-k4v、mod、cache。k4v 标注实验性。
- 任意 n-gram 子集可单独使用，也可与 MTP 联合使用。启动器生成一个 spec-type；执行优先级交给运行库，不提供无效的用户排序。
- 未新增 DFlash、EAGLE、DSpark 的模型登记或验证。

## 新增参数完整性

| 类型 | 可配置参数 |
| --- | --- |
| ngram-simple | spec-ngram-simple-size-n / size-m / min-hits |
| ngram-map-k | spec-ngram-map-k-size-n / size-m / min-hits |
| ngram-map-k4v | spec-ngram-map-k4v-size-n / size-m / min-hits |
| ngram-mod | spec-ngram-mod-n-match / n-min / n-max |
| ngram-cache | lookup-cache-static / lookup-cache-dynamic（均可不选） |

共 12 个数值参数与 2 个缓存路径。未设置数值以 null 保存，不显式传递；显式的 0 或默认值数值仍保留。长度参数上限按当前上游解析器的 1024 校验；mod 最小/最大草稿长度允许 0。命中次数为 1～65535：上游创建映射时使用 uint16_t，不能将更大数值直接传入造成截断。

simple 的 min-hits 在部分上游版本仅被解析、未参与算法，界面说明此限制；启动器仍忠实保存和传递用户设置，不伪造其效果。cache 在当前上游构造路径中没有开启动态缓存保存，不能承诺退出写回或持续学习。

依据：[上游说明](https://github.com/ggml-org/llama.cpp/blob/master/docs/speculative.md)、[参数解析](https://github.com/ggml-org/llama.cpp/blob/master/common/arg.cpp)、[调度与缓存实现](https://github.com/ggml-org/llama.cpp/blob/master/common/speculative.cpp)。适配基于用户实际运行库的帮助文本，不能将上游 master 的支持情况当成本机能力证明。

## 配置一致性与启动

- ModelProfile.Ngram 保存总开关、已选类型、全部数值参数及缓存路径；默认参数快照也保留这些值。
- 关闭策略/总开关不清空选择和参数。界面不因运行库不支持而自动取消已保存的选择。
- 保存读取实际控件值，拒绝错误输入。未知类型、重复类型、未知参数及 n-gram 对象内未知字段拒绝载入，不静默丢弃。
- 含 n-gram 用户设置的文档写入 FormatVersion=2；本版兼容读取 1 和 2。旧启动器会拒绝版本 2，避免忽略或覆盖新增选择；无 n-gram 设置的普通文档仍写版本 1。
- 启动沿用当前预选 JSON 解析链路。BAT 与 Router preset 共用参数生成；关闭策略的参数不会传递；不允许附加参数绕过结构化设置或启用 synthetic acceptance。
- 启动重新核对实际运行库声明的具体策略及显式参数，不仅检查 --spec-type 是否存在。无法确认时拦截，不自动退回普通模式。
- 帮助文本默认值参与 mod 最小/最大草稿长度的交叉校验，支持换行显示的帮助内容。
- 缓存可采用绝对路径或运行库相对路径，拒绝控制字符及含糊的驱动器相对路径。启动前检查所选文件可读且非空；不读完整缓存、不新建、不删除、不覆盖缓存。统计内容是否与分词器匹配、二进制格式是否受运行库支持，仍需由正确的文件来源及运行库实际加载确认。
- 缓存缺失时，允许载入配置供修正；启用并引用该文件的配置不能保存/启动。关闭 cache 或 n-gram 后可以保留路径并保存。
- 模板、MTP、思考与上下文滚动的临时能力检测关闭新增 n-gram 策略，仅调整临时副本，不改用户 JSON。

## 严格审查发现与修复

1. 缓存被删除后，模型登记中的历史运行设置可能使模型列表过滤该模型。回归测试先复现失败，再将登记验证与新运行参数分开。现在保留模型、资源管理与类型修改，配置内容不被改写；正式启动仍拦截缺失文件。
2. 帮助默认值可能换行显示。按选项块读取，避免漏掉默认值，导致显式最大值与隐含最小值冲突未被发现。
3. 驱动器相对路径可能依赖进程当前目录而指向不同文件。明确拒绝；绝对路径或相对运行库的路径保持确定性。
4. 旧启动器可能忽略新字段。使用文档版本 2 保护有新增设置的配置，防止静默偏差。
5. 上游映射命中次数存在 uint16_t 转换。限制安全范围，避免用户保存的数值与实际执行值截断不一致。

未发现仍未处理的阻断性代码问题。未修改在线恢复、认证传递、模型身份、模式切换或核心模型调用协议。新增策略会改变推测解码方式及其资源开销，不能据此宣称所有模型、后端及组合已实测稳定或更快。

## 诊断覆盖

复用 DiagnosticJournal：简易记录 ngramEnabled、ngramTypes、阶段与结果；详细模式额外记录参数和缓存文件名。失败沿用 validation_failed 等分类，不记录每次控件操作或缓存内容。原有原生日志接收链路继续保留运行库实际输出的性能统计，不自行推算接受率。

## 实现结果

- 首页启动卡片右上角使用现有 `CardCornerIconButtonStyle`（34×34），图标 20×20，复用矢量图标线宽。强调色钥匙代表开启，普通色带斜线钥匙代表关闭；提供中英文悬停、无障碍状态与保存失败提示。
- 全局字段 `LauncherSettings.LocalRequiresOpenAiAuth` 保存在启动器 `settings.json`。新安装、旧设置缺少字段时默认 `false`。不增加模型参数字段，不回写模型 JSON。
- 点击仅保存全局选择；新启动经 `ModeSwitchCoordinator` 将该值传入 `ChatGptLocalModeRequest.RequiresOpenAiAuth`，由现有 TOML 事务生成 `requires_openai_auth`。同模型再次启动也更新该值；前台与后台启动共用此路径。
- 置灰复用 `IsModeSelectionLocked`、`IsLocalRuntimeSessionActive` 和现有 Runtime 的 llama-server 进程判断，接入 `RefreshEggUiState`；没有新增轮询器或独立状态跟踪。没有选择模型或配置时也能设置认证。点击会强制刷新客户端状态，保存期间通过现有 busy 状态防止重复操作。
- 本地会话运行时禁止修改；全局字段不加入 Router 启动指纹，避免把偏好变更变成服务重启指令。在线恢复保留最新偏好，未完成事务恢复也不会用旧快照覆盖它。
- 主窗口客户端检测字段改为现有 `IChatGptClientDetector` 接口，实际仍使用原有 `ChatGptClientDetector`，便于隔离检查，不改变检测实现。
- 离线历史 Provider 和能力检测的隔离 CLI Provider 保持各自原用途，不用全局开关替换这些特殊路径。没有更改 auth.json、登录凭据或退出登录流程。

## 审查结论

本次变更未发现阻断交付的问题。重点检查了默认值、保存后延迟生效、同模型重复启动、端点迁移、在线恢复、未完成事务恢复、用户 JSON 与认证凭据不受改动、禁用按钮与事件处理的共同约束。

# 默认思考强度及思考设置布局：小规模审查（2026-10-07）

基于当前 0.9.7 思考显示测试版，仅新增默认强度选择，既有功能只调整界面位置。

## 实现

- 思考设置按检测思考能力、调节思考强度、启用思考排序，保留原有单个背景容器，区域之间使用两条分割线。既有检测按钮、取消按钮、模板状态、检测状态、已确认档位、详情折叠、档位开关、反转开关、思考开关及显示开关的事件和原有文案保留。原默认档位文本移除。
- 新增不可自由输入的默认强度下拉框，包含沿用模型默认及当前模型实际验证的原始档位。可操作状态直接沿用反转开关的状态；关闭或检测中保留偏好。
- PreferredReasoningLevel 为每个模型单独保存的可空偏好，不覆盖检测结果 DefaultReasoningLevel。支持保存为模型默认及恢复默认；取消编辑不改变原 Profile。
- 本地模型目录和 Codex 配置使用相同的 ReasoningDefaultSelection.ForCodex，精确传递已验证的用户选择；无选择或选择失效时沿用有效的模型默认，不映射档位。档位调节不可用时不传递默认强度。
- 当检测结果明确验证为可用、但此前用户选择不再属于该结果时，保存前提示并回退为沿用模型默认。能力尚未确认时仅保留偏好，不传递失效值。
- 显示反转只影响模型目录中的排列，不改变默认值。新增偏好不参与思考及上下文滚动能力指纹，既有有效验证无需重做。
- 模型推理参数、模板生成、检测过程、思考过程显示兼容处理及其他现有开关的业务逻辑没有为本次布局调整而改变。

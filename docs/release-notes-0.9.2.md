# Egg Launcher 0.9.2 本地版本说明

v0.9.2 于 2026-09-24 在本地 Git 仓库封存。此版本记录当前源码和功能范围，不代表已完成对外发布的全部验证或签名。

## 本版内容

- 模型参数窗口各选项卡统一内容背景宽度和底部按钮位置；高级参数加入 llama.cpp 原生 `--ctx-checkpoints`。留空沿用 Runtime 默认值，0 表示关闭检查点，不改变 Codex 的上下文压缩机制。
- 模型管理、社区模型搜索页面支持嵌套结果框与外层页面之间的滚轮接力；搜索页底部关闭按钮对齐结果框右边缘。
- 每个模型可单独保存 Codex 命令沙箱设置：联网沿用默认、禁用或完整联网，以及额外绝对路径的只读或读写权限。模型 Profile 结构版本升为 7；旧 Profile 未设置时继续沿用既有 Codex 沙箱配置。审批策略不由此功能修改。
- Local 模式切换事务应用当前模型的命名权限配置，切换模型或返回 OpenAI 时恢复相应沙箱字段。Codex 命名权限配置仍为 beta；不支持的配置组合会停止切换并报告冲突。
- OpenAI 模式保留由启动器管理的未激活本地历史 Provider 定义，让客户端能够识别、打开并查阅旧 Local 任务。该定义指向不可用的回环端口，仅用于历史解析，不会接管官方请求。

## 跨模式任务边界

0.9.2 支持跨模式查阅原有项目和任务。原任务跨 Provider 续聊的第二阶段已放弃：可行性验证表明，Desktop 对旧任务续发消息时仍可能使用任务创建时的 Provider；仅切换当前模式或模型不足以可靠改变原任务路由。启动器不会改写会话文件、伪装历史 Provider 或把请求静默转给另一模型。需要换模式继续工作时，请在目标模式中新建任务并引用原任务内容。详见 [ADR 0004](architecture/0004-cross-provider-history-boundary.md)。

## 验收与限制

- 当前源码先前的 Release 构建已通过；此标签的自动化测试和完整沙箱真机验收尚未执行。请以 [真机验收清单](manual-acceptance-checklist.md) 继续验证。
- 用户已确认在 OpenAI 模式能够查阅旧 Local 项目；这不等于所有客户端版本和所有跨模式组合均已验收。
- 完整联网不按域名细分，仍受 Codex 代理和管理员策略约束。若原配置含完整磁盘访问、无法等价表示的临时目录排除，或已有同名 `permissions.egg_launcher_active`，事务会停止，避免覆盖或静默改变权限。
- 模型在线下载仍为实验性；AMD/Vulkan、不同 llama.cpp 构建以及无官方账户的新安装环境仍需更多真机验证。
- 本地测试 ZIP 如未签名，仅供验收；正式对外发布须完成签名、依赖审计、自动化与手工验证。

# 0.9.9 发布检查记录

发布日期：2026-10-20（Asia/Shanghai）。软件版本 0.9.9，程序集/文件版本 0.9.9.0。

## 授权与源码依据

- 用户反馈最新测试包较稳定，明确授权同步相关 Markdown、源码、本地 Git、GitHub 和正式发布包。
- 文档以源码为准：主要依据 `ProfileEditorWindow`、参数与配置模型、资源验证投影、配置事务、Router 日志读取、Agent 状态与仪表盘显示。更新日志在启动器内同步中英文 13 项，日期 2026-10-20。
- 最新开发门禁为 894 项全量自动化测试、Release 零警告/零错误；接受率 UI 180 项、整数 K 输入 466 项、参数说明 6,804 项隔离检查对应各次范围。历史阶段测试数量不代表最终构建总数。
- 用户整体稳定反馈不扩大为新版全新安装、覆盖升级、卸载恢复、全部模型或异常注入矩阵均已逐项验收。历史 Win10 CUDA/Vulkan/CPU 与 0.9.7 安装反馈保留；Windows 11、ROCm 未验证。

## 本版边界

- 保存、应用、另存验证格式、范围、直接依赖、模型/路径绑定和自定命令冲突；新启动校验实际启用资源、证据与运行库支持，不静默关闭功能。
- 模板、思考、MTP 和滚动检测使用各自必要参数投影。视觉仍是元数据识别，不新增真实图片推理验证；重新检测不修改引用它的用户 JSON。
- 新固定参数、n-gram、自定参数的用户意图使用配置格式 2；读取旧格式 1，Profile schema 13 不变。JSON 保存完整意图，生成器只传递已设置且适用的参数。
- 自定 Codex 键进入既有恢复事务，固定与自动管理键不能覆盖；不支持结构或外部冲突停止覆盖。恢复继续保留未激活的本地历史 Provider，不承诺原文件逐字相同。
- K 输入只换算显示/输入单位；接受率只搬运当前运行中 llama 单请求原生统计。无新数据保持，换运行清空；不据此宣称 MTP 或 n-gram 一定提速。

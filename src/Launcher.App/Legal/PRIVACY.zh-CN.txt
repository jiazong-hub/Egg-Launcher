Egg Launcher 隐私说明

文档版本：0.9.1
生效日期：2026 年 9 月 19 日

1. 适用范围

本说明适用于 Egg Launcher 桌面应用本身。ChatGPT Desktop、OpenAI 服务、llama.cpp、Hugging Face、GitHub、本地模型及其他第三方软件或服务拥有各自独立的隐私政策和数据处理规则，不属于 Egg Launcher 的控制范围。

2. 不设置开发者服务器和外发遥测

当前版本不设置 Egg Launcher 账户体系或开发者服务器，不包含广告、外发使用分析、行为追踪或崩溃上报，也不会把本地诊断信息或性能采样自动发送给开发者或第三方。

Egg Launcher 不出售用户数据，也不会为了广告或用户画像处理数据。

3. 本地处理的数据

为完成用户请求的功能，Egg Launcher 会在本机处理或保存以下信息：

- 应用设置、主题、启动选项和已选择模式；
- llama.cpp Runtime 路径、模型路径、模型 Profile 和推理参数；
- 模式切换状态、受管理配置快照和恢复记录；
- 运行状态、进程信息以及 CPU、内存、GPU 和显存等本机性能数据；
- 通过本机回环地址读取的 llama 运行指标，例如生成速度和上下文占用；
- Agent、代理和 llama.cpp 产生的本地诊断日志；
- 用于恢复官方配置的本地备份。

Egg Launcher 不读取或复制账户认证凭据。需要保护的官方配置备份使用 Windows DPAPI 加密，只能由当前 Windows 用户解密。

上述本地性能数据和 llama 运行指标仅用于当前界面显示，不会作为遥测自动发送给开发者或第三方。

4. 网络访问

Egg Launcher 本身没有开发者运营的网络服务。以下网络访问只会在相应功能或用户操作发生时出现：

- 用户主动搜索或下载公开 GGUF 模型时，应用或所选 llama.cpp Runtime 会访问 Hugging Face；
- 用户主动打开 llama.cpp 下载页面或未来配置的项目链接时，系统默认浏览器会访问对应网站；
- OpenAI 模式的服务通信由 ChatGPT Desktop 及其服务处理，不是 Egg Launcher 的遥测或数据收集；
- Local 模式通过本机回环地址与本地 Agent、代理和 llama.cpp 通信。

当前版本不包含自动更新检查。未来如果加入更新检查或其他新的联网功能，会在启用前更新本说明，并在界面中明确标示。

5. 日志与敏感信息

Egg Launcher 自身的结构化代理日志不记录提示词正文、响应正文、认证头、Cookie 或完整账户元数据。但 llama.cpp 原生日志的具体内容由用户所选 Runtime 决定，可能包含模型名称、文件路径、参数、硬件和运行错误。

用户在公开分享日志、截图或配置文件前，应自行检查并移除个人路径、账户信息、模型私有信息及其他不希望公开的内容。

6. 保存位置与保留期限

Egg Launcher 的主要应用数据保存在当前 Windows 用户的以下目录：

%LOCALAPPDATA%\ChatGPTLocalLauncher

模型文件、Profile、脚本、模板和 Router preset 可能保存在用户选择的 llama.cpp Runtime 目录中。应用不会把这些本地文件自动上传给开发者。

本地数据通常保留到用户主动删除、卸载或使用相关清理功能为止。删除应用程序文件不会自动删除用户数据、Runtime 或模型；用户应根据需要分别清理。

7. 系统权限与开机启动

应用只在用户明确启用后为当前 Windows 用户注册开机启动项。关闭该选项会移除受管理的启动注册。应用不要求管理员权限来完成常规配置和使用流程。

8. 用户选择

用户可以不使用模型搜索和下载功能，从而避免由这些功能发起的外部网络请求；也可以关闭开机启动、删除本地日志或停止 Local 后台服务。Local 和 OpenAI 模式的选择由用户控制。

9. 儿童隐私

Egg Launcher 不面向儿童提供账户或在线服务，也不会主动收集年龄信息。用户使用第三方模型或服务时，应遵守相应服务的年龄要求和监护规则。

10. 本说明的更新

本说明可随功能和数据处理方式变化而更新。新版本会标注文档版本和生效日期。如果未来增加外发遥测、开发者服务器、账户、云同步或其他实质性数据处理，将在功能启用前提供清晰说明和适当选择。

11. 联系与反馈

公开源代码仓库和问题反馈地址将在项目准备完成后补充。用户可通过“关于 Egg Launcher”窗口查看当前软件版本随附的隐私说明。
